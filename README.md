# skills

A collection of skills crafted for quality of life with your AI coding agent.

## Install

```bash
# Install all skills
npx skills add aayushbtw/skills

# Install a specific skill
npx skills add aayushbtw/skills --skill git-commit
```

## Skills

| Skill | Description |
|-------|-------------|
| [git-commit](./git-commit/SKILL.md) | Stage files and commit with a conventional commit message |
